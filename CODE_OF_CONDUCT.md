# Code of conduct / Правила поведения

**English**

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, keep discussions technical, no harassment of any kind.
Unacceptable behavior can be reported privately to the maintainer via the email in the GitHub profile
[@salilov95](https://github.com/salilov95).

**Русский**

Проект следует [Contributor Covenant, версия 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (на сайте есть переводы).
Коротко: уважительно, по делу, исходя из добрых намерений, без оскорблений и давления.
О недопустимом поведении можно сообщить сопровождающему лично - через почту в профиле GitHub
[@salilov95](https://github.com/salilov95).
