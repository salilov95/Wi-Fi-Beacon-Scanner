## Что проверяется (находки)

Всего 29 проверок. У каждой находки в программе есть пояснение и подсказка «что проверить».

Находки считаются по всему эфиру. Проблемы конфигурации и слабого сигнала - только для «Моих SSID»,
чужие сети учитываются как помеха на канале. В отчёт попадают находки, которые касаются выбранных сетей.

## Шкала сигнала

Везде одна шкала от красного к зелёному: −85 дБм и ниже красный, −75 оранжевый, −67 жёлтый, −60 салатовый,
−50 и выше зелёный. Ориентиры: от −67 и сильнее хватает для голоса и видео, −67…−72 для данных, слабее −75
клиенты начинают терять скорость и роумиться. Загрузка канала окрашена наоборот: до 30% свободен,
30–50% умеренная, 50–70% высокая, от 70% перегружен.

## Загрузка канала

Берётся из QBSS Load (IE 11) в beacon: доля времени, когда сама AP считает канал занятым, и число станций.
Вещают не все AP: нет IE - нет цифры, а не «0%». На канал берётся максимум среди AP, которые сообщают загрузку.

## MCS и максимальная скорость

Beacon не содержит «текущий MCS». В нём есть то, что AP умеет:

- HT Capabilities: Rx MCS bitmask (например, MCS 0-15 = 2 потока), Short GI 20/40;
- VHT Capabilities: Rx/Tx VHT-MCS map по потокам (MCS 0-7/0-8/0-9), Short GI 80/160, ширины сверх 80 МГц, beamforming;
- HE Capabilities: Rx/Tx HE-MCS map до 80 МГц и для 160 МГц (MCS 0-7/0-9/0-11);
- HT/VHT/HE Operation: Basic MCS Set - минимум, который AP требует от всех клиентов; в HE Operation ещё
  BSS Color и для 6 ГГц ширина и центр канала (раньше 6 ГГц всегда считался 20 МГц).

Из этого считается «Макс. PHY»: скорость канального уровня по формуле стандарта для старшего MCS, числа
потоков AP, рабочей ширины канала и самого короткого GI, который AP поддерживает. Это потолок при идеальном
сигнале и клиенте с тем же числом потоков, а не пропускная способность (TCP получится примерно вдвое меньше).

MCS, с которым реально идут кадры, виден только в monitor mode (radiotap), Native Wifi API его не отдаёт.
Для своего подключения Windows сообщает скорость приёма и передачи; программа подбирает MCS, число потоков,
ширину и GI, которые дают ровно эту скорость (вкладка «Подключение», «MCS по скорости»). Совпадений бывает
несколько (MCS 4 на 2 потока и MCS 8 на 1 поток почти равны), первым показан вариант с шириной BSS и двумя
потоками, остальные в подсказке. EHT (Wi-Fi 7) MCS пока не разбирается: для таких AP показан HE-потолок.
