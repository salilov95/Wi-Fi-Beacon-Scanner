# Установка и раздача на ноутбуки

[← README](../../README.ru.md) · [English](../en/deployment.md)

## Файлы релиза

Страница [Releases](https://github.com/salilov95/Wi-Fi-Beacon-Scanner/releases):

- `WiFiBeaconScanner2-Setup-<версия>.exe` - установщик для текущего пользователя (без прав администратора, ярлык
  в «Пуске», запись в «Установленных приложениях», штатное удаление);
- `WiFiBeaconScanner2.exe` - переносная версия одним файлом, без установки;
- `SHA256SUMS.txt` - контрольные суммы.

Нужны Windows 10 или 11 (x64) и среда Microsoft Edge WebView2. Она входит в Windows 11 и приходит в актуальную
Windows 10 с обновлениями Edge; если её нет, установщик скачает её сам (нужен интернет), а переносному exe она
нужна уже установленной.

Тихая установка для раздачи на много ноутбуков (SCCM, Intune, GPO, PDQ) - запускать в контексте пользователя,
программа ставится для него:

    WiFiBeaconScanner2-Setup-2.0.0.exe /S

Тихое удаление:

    "%LOCALAPPDATA%\Wi-Fi Beacon Scanner 2\uninstall.exe" /S

Новая версия ставится поверх старой. Версия 2 ставится рядом с 1.x и её не трогает: у них разные папки,
настройки и ярлыки. 1.x удаляется отдельно («Параметры» → «Приложения»), когда станет не нужна.

Файлы не подписаны сертификатом. При ручном запуске скачанного файла SmartScreen покажет
«Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае»; при раздаче через
SCCM/Intune/GPO этого окна нет. Чтобы убрать предупреждение совсем, нужен сертификат подписи кода
(корпоративный PKI или OV/EV) и `signtool`.

Журнал программы: `%LOCALAPPDATA%\WiFiBeaconScanner2\logs\app.log` - его стоит прислать, если что-то пошло не так
(«Вид» → «О программе» → «Папка с журналом»).

## Где программа хранит данные

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Wi-Fi Beacon Scanner 2` (`wbs-app.exe`, `uninstall.exe`) |
| Ярлык в «Пуске» | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Wi-Fi Beacon Scanner 2.lnk` |
| Настройки вида, язык, «Мои SSID», ширина столбцов | `%APPDATA%\WiFiBeaconScanner2\prefs.json`; пока его нет, берутся настройки 1.x (`%APPDATA%\WiFiBeaconScanner\prefs.json`), файл 1.x не меняется |
| Журнал программы | `%LOCALAPPDATA%\WiFiBeaconScanner2\logs\app.log` (до 1 МБ и три прошлых файла): запуск, сканы, ошибки страницы |
| Профиль WebView2 окна | `%LOCALAPPDATA%\io.github.salilov95.wifibeaconscanner2` |
| Выгрузки | куда сохранил пользователь; сама программа больше ничего не пишет |

Удаление убирает программу и ярлык; настройки, журнал и профиль WebView2 остаются (при необходимости три папки
выше удаляются вручную).

## Язык интерфейса

Русский или английский. При первом запуске программа берёт язык интерфейса Windows (русский для русской
Windows, иначе английский); пользователь переключает его в «Вид» → «Язык», выбор сохраняется в `prefs.json`
(`"lang": "ru"` или `"en"`). Для всего парка язык можно задать в этом файле или ключом `--lang ru`
(на один запуск). Проблемы, расшифровка beacon и отчёты PDF/Excel/HTML - на том же языке. Сообщения журнала
Windows показываются так, как их отдаёт Windows, на языке системы; события журнала подключения остаются
на языке, на котором были записаны.

## Параметры запуска

| Параметр | Что делает |
|---|---|
| `--demo [скан.json]` | демо-режим без Wi-Fi: встроенный офис или свой сохранённый скан, с демо-журналом подключения |
| `--ssid ИМЯ` | «Мои SSID» на этот запуск (можно несколько раз; работает и `--ssid=ИМЯ`) |
| `--manuf ПУТЬ` | база вендоров (файл `manuf` из Wireshark) вместо встроенной |
| `--lang ru` / `--lang en` | язык интерфейса и отчётов на этот запуск |

Параметры 1.x `--port`, `--no-browser` и `--keep-running` принимаются и пропускаются: у версии 2 нет локального сервера.

## Как программа работает

Окно - WebView2; страница и программа общаются внутри процесса, через свой протокол программы `wbs`. Локального
сервера и открытого сетевого порта нет. Закрыли окно - программа завершилась.

Сама в интернет программа не ходит. Единственное исключение - «Вид» → «Проверить обновления»: один запрос
к `api.github.com` (через системный прокси Windows).

PDF-отчёт печатает установленный Microsoft Edge (без окна). Если печать без окна запрещена политикой, программа
покажет причину и предложит открыть отчёт, чтобы сохранить его в PDF через Ctrl+P.

## Ограничения

- Проверено на ноутбуке с MediaTek Wi-Fi 6 MT7921 (Windows 11): скан, окно, журнал подключения, сессии
  и журнал Windows. Разбор причин отказа 802.1X на реальных отказах ещё не сверялся.
- Это не monitor mode: мы видим то, что отдаёт служба WLAN AutoConfig. Ретрансмиты, EAPOL,
  roaming-кадры так не увидеть.
- Windows ограничивает частоту сканов; `WlanScan` может вернуть ошибку, тогда читается кэш.
- С Windows 11 24H2 сканирование Wi-Fi требует разрешения на расположение. При первом скане Windows сама
  показывает запрос; пока доступа нет, `WlanScan` и `WlanGetNetworkBssList` возвращают `ERROR_ACCESS_DENIED`.
  Программа показывает плашку с кнопкой «Открыть параметры расположения» и повторяет скан автосканом.
  Для раздачи через GPO/Intune: «Конфиденциальность → Расположение → Разрешить классическим приложениям
  доступ к расположению» должно быть включено.
- Загрузка канала и число станций берутся из QBSS Load, который вещают не все AP.
  Нет IE - нет цифры, а не «0%».
- Номера Extension ID для Wi-Fi 7 (EHT: 106/108) нужно сверить с актуальной редакцией
  802.11be, пока определение «Wi-Fi 7» не подтверждено реальной AP.
- Снапшот содержит SSID и BSSID всех сетей в округе: перед отправкой кому-либо проверь, что это допустимо.
